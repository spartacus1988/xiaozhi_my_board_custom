=============================================================
  ПРОШИВКА ESP32-S3 С ДИСПЛЕЕМ 1.54" TFT (XIAOZHI ESP32)
=============================================================

1. УСТАНОВКА ESP-IDF
--------------------
- Скачайте и установите ESP-IDF v5.4 или новее:
  https://docs.espressif.com/projects/esp-idf/ru/latest/esp32s3/get-started/
- Для Windows используйте ESP-IDF Command Prompt
- Для Linux/macOS выполните: source ~/esp/esp-idf/export.sh

2. КЛОНИРОВАНИЕ ПРОЕКТА
-----------------------
git clone https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32

3. ДОБАВЬТЕ ВАШУ ПЛАТУ
----------------------
Скопируйте папку my-esp32s3-1.54tft/ в main/boards/
(файлы config.h, my_board.cc, config.json)

4. НАСТРОЙКА ПРОЕКТА
--------------------
idf.py set-target esp32s3
idf.py menuconfig

В меню перейдите:
  → Xiaozhi Assistant → Board Type
  → Выберите "my-esp32s3-1.54tft"

5. СБОРКА
---------
idf.py build

6. ПОДКЛЮЧЕНИЕ ПЛАТЫ
--------------------
- Подключите ESP32-S3 к компьютеру через USB-кабель
- Определите порт:
  * Windows: COM3, COM4 и т.д.
  * Linux: /dev/ttyUSB0 или /dev/ttyACM0
  * macOS: /dev/cu.usbserial-*

7. ПРОШИВКА
-----------
idf.py -p ПОРТ flash

Пример для Windows:  idf.py -p COM3 flash
Пример для Linux:    idf.py -p /dev/ttyUSB0 flash

8. МОНИТОРИНГ (проверка логов)
-------------------------------
idf.py -p ПОРТ monitor
(Нажмите Ctrl+] для выхода)

9. ПОДКЛЮЧЕНИЕ К WI-FI И НАСТРОЙКА
----------------------------------
- После прошивки плата создаст Wi-Fi точку доступа
- Подключитесь к ней и откройте в браузере 192.168.4.1
- Настройте Wi-Fi и сервер xiaozhi.me

10. ГОЛОСОВОЕ УПРАВЛЕНИЕ ЭКРАНОМ
---------------------------------
После подключения к серверу скажите:
  • "Включи экран"
  • "Выключи экран"
  • "Установи яркость 50%"

=============================================================
  УСТРАНЕНИЕ ПРОБЛЕМ
=============================================================

ПРОБЛЕМА: Ошибка при сборке
РЕШЕНИЕ: Проверьте, что вы выбрали правильную плату в menuconfig

ПРОБЛЕМА: Экран не включается после прошивки
РЕШЕНИЕ: Проверьте пины в config.h — особенно DISPLAY_BACKLIGHT_PIN

ПРОБЛЕМА: Плата не определяется по USB
РЕШЕНИЕ: Установите драйвер CP210x или CH340 (для Windows)

ПРОБЛЕМА: Подсветка не управляется голосом
РЕШЕНИЕ: Убедитесь, что плата подключена к серверу xiaozhi.me
